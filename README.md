# BoomThere · 桌面空袭特效

Windows 常驻小程序：在任意普通桌面窗口上 **按住 Ctrl 并点击鼠标右键**，立即以点击位置为中心播放一次约 3 秒的空袭轰炸动画。动画结束自动清理，不破坏桌面内容、不阻挡鼠标。

## 使用

```
Alt  + 右键        →  唤出技能轮盘（常驻），左键点选技能发射，右键/点空白取消
托盘图标右键       →  设置 / 退出
```

- 轮盘打开期间进入钩子屏蔽模式：所有鼠标输入被拦截（不会误触下层应用），点选由钩子转发判定；15 秒无操作自动取消，退出程序自动解除。
- 托盘「设置」可改轮盘触发修饰键（Alt/Ctrl/Shift，存于应用数据目录 config.json，立即生效）并开关特效音效。
- 技能注册表化：往 `src/main.ts` 的 `registerSkills` 加一条即可让轮盘多一片，当前「给我炸」可用，另有三个"敬请期待"占位片。
- 轮盘为 POLARIS 浅色能量风格（600×600 基准坐标系整体缩放）：白色玻璃装甲 + 四块独立悬浮扇区 + 珊瑚红中心取消钮；外圈包含正转青蓝/淡紫断环、反转 96 格刻度环、柔和雷达扫光、轨道光点和闪烁星尘；主题色全部集中在 `menu.ts` 的 `THEME` 常量；支持 Normal/Hover/Pressed/Disabled/Selected 五态，打开弹入/反向解锁、悬停发光抬升、关闭收缩。

普通右键完全不受影响；特效播放期间鼠标穿透，仍可正常操作下层软件；同一时间只播一场，连点不会叠加。

## 开发

```bash
npm install          # 安装依赖
npm run tauri dev    # 启动桌面应用（vite + Rust 同时跑）
npm run dev          # 仅前端：浏览器打开 http://localhost:5173
                     #   左键播放「给我炸」，Alt+右键按住拖拽体验轮盘
npm run tauri build  # 打包 NSIS 安装包 + 独立 exe
npm run icon         # 重新生成 src-tauri/icons/icon.ico
```

## 技术栈与职责

| 技术 | 职责 |
| --- | --- |
| Tauri 2 + Rust / Win32 | 程序外壳、`WH_MOUSE_LL` 低级鼠标钩子、事件分发、覆盖层窗口控制 |
| Vite + TypeScript | 前端构建与业务逻辑 |
| PixiJS 8 | 透明 WebGL Canvas、战机/炸弹绘制、火花烟雾粒子、爆炸 |
| GSAP | 时间轴调度：锁定 → 入场 → 投弹 → 起爆 → 消散 |

## 执行链路

```
Win32 鼠标钩子识别 Ctrl+右键 (input.rs)
  → 采集物理屏幕坐标，经 channel 交转发线程（回调内不做重活）
  → 发出 airstrike-trigger { screenX, screenY } (lib.rs)
  → 前端扣除覆盖层左上角偏移 + DPI 缩放换算成本地坐标 (main.ts)
  → playAirstrike(localX, localY) (airstrike.ts)
  → 播放动画 → 粒子耗散 → 销毁全部对象 → 恢复空闲
```

## 特效时间轴（约 3.05 秒）

| 时段 | 内容 |
| --- | --- |
| 0.0–0.4 s | 全息瞄准圈锁定点击点（虚线环 + 反向旋转跟踪括弧 + 雷达扫描扇形 + 八向刻度 + TGT LOCKED） |
| 0.3–1.6 s | 机甲战机（高达风涂装：白装甲/红鼻锥/黄 V 鳍/青色座舱，双喷口加力焰 + 翼尖航行灯）自屏幕边缘飞入 |
| 1.0–1.6 s | 投放智能炸弹（白装甲弹体 + 青色能量芯 + 等离子光环），导引激光从机头直射目标，青色倒计时环随弹收紧，抛物线坠落拖出等离子尾迹 |
| 1.6–2.3 s | 起爆：青白能量闪、垂直光柱、火球、等离子流、双冲击波环（白+青）、火花碎屑、镜头微震（仅特效层内部） |
| 2.0–3.05 s | 升腾烟雾、余烬淡出；全部粒子耗散后才停渲染循环，不留任何地面残影 |

## 代码结构

```
src/
  main.ts                  # 启动、事件订阅、坐标换算、技能注册、浏览器预览模式
  effects/menu.ts          # Light Sci-Fi 轮盘组件（RadialMenu：数据驱动 + 分层渲染 + 五态）
  effects/airstrike.ts     # playAirstrike(x, y)：GSAP 时间轴与清理
  effects/particles.ts     # 程序化贴图 + 火花/烟雾/尾焰/冲击波粒子系统
  effects/audio.ts         # WebAudio 合成音效（引擎轰鸣 + 爆炸，零素材）
  engine/pixi.ts           # PixiJS 8 初始化（透明画布、空闲时停 ticker、rAF 节流看门狗）
  settings.ts / css        # 设置面板页（快捷键、音效开关）
src-tauri/src/
  lib.rs                   # Tauri 初始化、配置装载与装配
  input.rs                 # WH_MOUSE_LL 钩子：技能触发 / 轮盘模式 / 可配置修饰键 / 卸载
  overlay.rs               # 覆盖层窗口、托盘（设置/退出）、设置窗口与命令
  config.rs                # 持久化配置（应用数据目录 config.json）
tools/make-icon.mjs       # 程序化生成 icon.ico（零素材）
```

## 素材策略

战机使用 640px Canvas 程序化矢量绘制并一次性烘焙为纹理：RX 风格机首 V 鳍、白蓝红三色分层装甲、金色细节、面板刻线、军规标识与双涡轮引擎；炸弹沿用 CC0 素材，粒子/冲击波贴图由 Canvas 径向渐变程序生成，音效由 WebAudio 噪声合成。后续可继续替换 `assets/` 下的爆炸 Sprite Sheet、烟雾纹理与 OGG 音效。

## 验收对照

- ✅ Ctrl+右键在选定位置播放空袭；普通右键不拦截（钩子仅在按住 Ctrl 时吞掉右键按下，并成对吞掉释放）
- ✅ 飞机 → 炸弹 → 爆炸 → 烟雾按顺序出现，总长约 3.05 秒
- ✅ 覆盖层透明置顶、始终鼠标穿透（`set_ignore_cursor_events(true)`，创建即生效）
- ✅ 同一时间只播一场；结束后销毁全部精灵/粒子/时间轴并停掉 ticker，无残留
- ✅ 退出时向钩子线程投递 `WM_QUIT` 并 `UnhookWindowsHookEx`；特效构建异常时立即清理恢复空闲
- ✅ 浏览器实测：锁定圈/战机/炸弹抛物线/爆炸/清理全部通过（含防叠加守卫）

## 已知限制（第一版范围外）

- 仅支持主显示器；未适配多显示器坐标与独占全屏游戏
- 低权限进程收不到管理员窗口上的钩子事件（Windows UIPI 限制，需以 UI Access 方式运行才能覆盖）
- 特效期间不破坏桌面内容，也无真实窗口破坏/桌面形变
- 圆盘菜单、多技能、设置页暂未实现
